## 模型运行

上一版本在上述独立环境中完成了一次完整推理：官方权重、示例口袋、1 个样本、1,000 步，得到 1 个可读取的连通分子。SDF、SMILES 与运行记录一致。本次只修改表格读取和说明，没有修改模型或重新运行 GPU 采样。

`sample_results/` 保留早先运行的参考结果。不同设备和依赖构建可能得到不同的采样结果，不要求文件逐字节相同。

## 自动检查

GitHub Actions 在 Ubuntu / Python 3.10 上安装数据依赖，运行测试、处理合成表格并核对结果。最新状态见[检查记录](https://github.com/songfy0118/protac-decompdiff-starter/actions/workflows/checks.yml)。没有安装 PyTorch 的任务会跳过一项模型结果导出测试。

CI 不运行 GPU 生成，也不下载大型权重。模型运行是单样本检查，尚无多种子、多口袋的统计评估。候选分子的结合能力和降解活性没有验证。
